## call expression
调用表达式
```python
>>> max(7.5, 9.5)
9.5
```

一个基本的调用表达式包括：
运算符（operator）+操作数表达式（operand expressions）
![[Pasted image 20260408000354.png]]


运算符可以理解为：**动作**
操作数表达式可以理解为：操作的对象，放在括号里，用逗号隔开

注意：操作数的位置不同，表达式的意义也不同
```python
>>> pow(100, 2)
10000
>>> pow(2, 100)
1267650600228229401496703205376
```


## 拓展：前缀、中缀、后缀

这三个概念分别代表的是运算符相对于操作数的位置。
### 中缀
中缀表达式：人类擅长读中缀
例如`1-2`,是我们在现实数学中常用的，
但是缺点也很明显：

```python
(1 + 2) * 3
```

涉及到乘法的时候，是我们不得不用括号来避免歧义

1. **优先级歧义**
看到 `3 + 4 * 5`，如果没有“先乘除后加减”的约定，你可以理解为 `(3+4)*5 = 35`，也可以理解为 `3+(4*5) = 23`
2. **结合性歧义**
看到 `10 - 5 - 2`，如果没有“从左往右算”的约定，它可以是 `(10-5)-2 = 3`，也可以是 `10-(5-2) = 7`

---
### 前缀
运算符位于所有操作数之前
例如
```python
+ 1 2
```

注意我们的函数调用表达式也符合前缀的模式
```python
add(1,2)
```

> 函数名称始终位于其参数


---
### 后缀

运算符位于所有操作数之后
```python
1 2 +
```
例如对于中缀表达式：

```python
(1 + 2) * 3
```

后缀形式就是： 

```python
1 2 + 3 *
```
后缀是通过栈的数据结构进行运算：

![[expression_postfixEval_1775630617984.gif]]

因此后缀表示在计算机中尤其常见。

## 导入库函数

默认情况我们不能直接调用函数，因为python的设计是将不同的需要重复使用的功能封装成一个函数（也叫做方法），每种方法归类放入了模块（modules）中。这些模块组成了库。因此当我们需要使用这些函数的时候应该预先声明导入这些库。
python的导入声明语法分为两种：

`import`语句和 `from...import`语句

`import`：导入整个模块，导入后如果需要使用则需要通过`.`来访问。
`from...import`:Python 依然会加载整个模块，但它只会在当前环境中创建一个名为 `sqrt` 的绑定，直接指向那个函数对象。不需要通过`.`访问，直接调用函数名。


例如，`math` 模块提供了各种熟悉的数学函数：
```python
>>> from math import sqrt
>>> sqrt(256)
16.0
```

```python
>>> import math 
>>> sqrt(256)
```
